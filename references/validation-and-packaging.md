# 验证与打包

## 分级证据

| 阶段 | 有效证据 |
|---|---|
| 静态 | 组合依赖、单位/方向、几何身份、可见性、物理 API、关系与配置有效 |
| 渲染 | 交付版本的实际外部/内部预览，材质与观察窗正确 |
| 默认静置 | 真实入口 Play 的时间、位移、倾角、速度、接触与支撑 |
| 动作 | 工具/物体实测运动、接触/连接、释放与负例拒绝 |
| 干涉 | 逐轴及相关多轴采样、实测行程、碰撞对、误差与采样条件 |
| Matterix 接入 | 实际目标环境加载、配置/资源/帧/动作/语义与 SDK 读回 |
| 多环境与 reset | 状态隔离、选择性重置及重复生命周期 |
| 连续工作流 | 同一环境连续完成指定流程的物理和语义状态轨迹 |

按范围选择阶段，给未运行和不适用原因。每份报告绑定入口及全部有效层、运行脚本/配置的版本或 hash，记录环境版本、硬件、输入、步数/时长、预先声明的容差、测量与退出状态。修改几何、碰撞、归属或动作后重测影响范围，旧报告保留为历史证据。

开发期先跑直接受影响检查；发布/交付时再跑适用整体检查。逻辑门控的合成位姿测试不能替代物理；冻结其他物体或关闭无关碰撞的夹具要列条件，不能当默认全场通过。各次 reset 后分别通过不代表连续工作流通过。

容差由对象尺寸、任务精度和数值分辨率确定，禁止为了抹去失败而事后放宽或跳过对象。对 CUDA illegal access、cooking 失败和原生崩溃保存证据并终止受损进程；修复后用新进程。GPU Xid/GSP 异常时停止 GPU 工作，不自行重置用户显卡。

## USD 合并与依赖闭包

小入口通常是引用层，检查递归依赖而非凭文件大小判断完整性。保留可编辑分层来源；合并写独立副本。

`Stage.Flatten` 是当前 composition 的快照。非激活 prim 的子树、未选择 variant、未加载 payload 不保证保留；后续需要动态激活的 closure/安装关节可能消失。导出前列出预期运行定义，在隔离 stage/session 中按需暴露后导出，再恢复交付所需初始状态。不得激活用户正在运行的场景来做快照。若一个快照无法包含必要运行定义，交付分层包。

核对合并前后：几何、材料、真实刚体、质量/惯量、关节/驱动/锚点/关系、帧、初始 active 状态和运行所需非激活定义。普通 `Traverse()` 会漏 inactive，审计应含 `TraverseAll()`；inactive 父节点下的后代在正常组合中仍可能不可见，需查来源定义或隔离激活比较。

合并不会把 Python 回调、控制器、纹理/MDL 和外部资源自动变成可执行 USD。引用 defaultPrim 也不会自动引入同文件的 sibling PhysicsScene；检查直接打开和 Matterix 引用两种路径的有效重力、时间步、接触参数与场景归属，避免重复创建冲突 scene。

## 分发包

包含推荐 USD 入口、所有层/纹理/必要材料、运行脚本、配置/导出补丁或明确接入模块、操作清单、可复现命令、来源许可、实际预览和对应验证报告。文档列出：源 ID—英文名—中文名—用途—所属体，关节的连接/轴/行程/驱动/功能，帧与控制接口，质量/惯量及参数来源。示例配置要明确待填项，不能冒充可运行命令。

包内路径相对解析，去除个人绝对路径、凭据、缓存、无关 CAD 与日志。校验 hash/ZIP CRC，并在不同持久路径解压后重新打开和运行最小入口；仅在原开发目录打开不足以证明可移植。按授权和许可决定是否包含源 CAD；发布 skill 不意味着允许发布源模型。

公开说明准确的验证级别和行为近似。简洁的用户说明可将细节放入技术报告，但不能让使用者误以为失败动作或估算参数已经通过实机验证。
