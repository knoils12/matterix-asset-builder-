# 操作与语义

## 从目标动作反查整条连接链

逐个核对实际工作流目标及其可达操作帧、物理所有者、语义类型和初始化状态。不能用一个不在任务工位的示例耗材证明其他目标可用。名称相似或位置匹配不等于具备操作接口。

对每个动作写清前提、物理执行、状态变化、可观察成功条件、逆操作与 reset。例如夹住盖提瓶需要 `工具→盖→瓶身` 连续连接，只有工具到盖的连接会把盖单独提走。过滤头需独立物理体、抓取/安装/出口帧及真实接口关系；仅挂在托盘下的视觉节点抓不起来。

## 自由取放与可拆安装

独立耗材有稳定身份、真实刚体、碰撞、质量/惯性与初始支撑，去除机构下重复视觉/碰撞。抓取与安装使用真实运动体的帧，校验距离、朝向、接触/闭合条件和占用状态后再建立约束。

分别验证接近、夹紧、抬升、运输、释放、支撑、工具退离与重抓，并测试错误对齐和错误占用被拒绝。记录工具/物体实测位姿、连接和接触。约束辅助抓取与纯摩擦抓取明确区分；辅助连接须可解除且不伪装为接触力验证。

可拆接口跟随实际被连接物，而非固定设备根。设备放开工具后，安装在工具上的部件仍应跟随工具；reset 恢复各自初态并解除运行期临时约束。

## 旋盖

瓶身/盖分别为可操作对象；逐个任务目标核对 closure、初始开闭状态、body0/body1 和锚点。闭盖运输要求瓶身跟随盖；开盖要求防转、相对转角/轴移及真实脱离；合盖要求对齐、接合条件和再次运输。自由盖被夹走不证明真实开盖。

螺纹可采用任务所需的几何接触或声明的螺距约束简化，说明螺距/圈数/力矩来源。以固定瓶身夹具做的旋盖测试只支持该条件；完整流程另测真实防转、换工具与取放顺序。

## 注射器、移液工具与液体

区分整体升降、筒身保持、活塞载体和两组手指。夹持面取实际突出平台/槽口，测量平台厚度、槽高、双侧接触与间隙。筒身保持时活塞上升/压缩对应吸入/挤出，整体运输不产生相对泵送；两组夹爪均能释放和重夹。重定位后重算锚点，避免旧补偿跳位。

选择与用户任务相称的液体模型：体积分舱可表达容量、液位与质量；需要自由液面、流动接触或粒子行为时再配置并验证相应物理模型。语义体积变化不能证明流体力学或真实过滤化学。

固定反应釜等也可具有容器 operation target，绑定真实父刚体与开口/容量；无需为了语义制造自由刚体或重复质量。初始化体积来自任务，不为让吸液测试通过而隐式填满。

吸液条件包括正确入口/出口、浸入液面、可用体积、工具容量和阀/盖状态；放液需有效接收器或明确洒落去向。过滤附件出口代替原工具尖端时，所有位置/浸入门控使用实际出口。

以实测相对泵送行程驱动体积更新，记录源/工具/目标/洒落与守恒误差。对静止抖动和整体移动做负例测试，避免逐帧单侧位移累加把零均值抖动整流为持续转移。阈值来自噪声与几何，属于仿真分辨能力，不是编码器标定。

若宣称液体改变质量/质心/惯量，读回实际 SDK 值并验证聚合一次。语义和物理状态按 env id 隔离，选择性 reset 恢复体积、连接、工具占用与动态质量；一个环境重置不能改变另一个环境。
