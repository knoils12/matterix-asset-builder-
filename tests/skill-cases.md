# 独立行为评估案例

这些是未执行的评估输入与判据，不是端到端通过报告。给评估助手对应的真实/合成输入和 skill，在隔离目录执行；不要提前把预期修复告诉它。实际评估记录模型、输入、轨迹、产物、成本和失败，再据此修改 skill。

| 输入任务 | 需要观察的行为 |
|---|---|
| 固定工作台 STEP，只需碰撞和 Matterix 加载 | 静态配置、尺寸/材质/接触证据；不虚构驱动或液体模型 |
| 有 URDF 和 mesh 的两指夹爪，要抓取空试管 | 复用 importer 与实际 joint/mimic，开口代理和目标环境真实抬升/释放；不照搬其他设备增益 |
| CAD 滑台，无材料和配合，要求动力学真实 | 保留源外形、明确轴/惯量的证据缺口；可追溯估算，不冒充实机标定 |
| 组合工作站，有自由盖、滤头、固定反应容器，要求提瓶和吸液 | 反查每个任务目标，补足实际连接/操作帧；语义目标不重复刚体质量；体积与质量守恒 |
| 分层 USD 需要合并，存在 inactive 父级下可复用连接 | 隔离导出、核对运行定义及初态、随包 Python/材料依赖；移动包重新打开并测最小入口 |

本仓库自动化测试只覆盖静态检查脚本。上述独立行为评估若缺转换器/GPU/目标环境，记录相应阶段 not_run，不能将规划或静态审计当成任务完成。
